# 남은 확인·업데이트 항목

이 파일의 미완료 사항은 원고 전체 작성을 막는 조건이 아니다. 중요한 과학적 한계는 해당 본문에도 기술한다.

- 보완 평가기 NOMINAL/LOW/HIGH: 확인한 세션은 not_run이다. 실제 시행이 추가되면 7장의 별도 결과표에 session/version별로 추가한다. 기존 15회 높이 기준만 바꾼 replay는 새 물리 시험이 아니다.
- E2 A4: 이번 사용자 지시의 현장 정정을 최우선으로 반영한다. 원 로그 operator_finish/normal_completion은 보존하며 별도 task outcome을 기록한다. A 동영상은 원 보고서 기준 5개 모두 부재다.
- 표면 품질: 깊이·질량·거칠기·미세 스크래치 제거율은 본 데이터로 평가하지 않았다. 표식 제거 영상과 혼동하지 않는다.
- 하위 제어기: 보관 소스와 설정으로 구현을 설명한다. controller-applied 목표 force 시간열이 없으므로 실제 추종오차는 산출하지 않는다.
- 하드웨어: UR10 인터페이스, Vive tracker, RealSense RGB, F/T sensing을 근거 있는 수준으로 쓴다. 공구/센서 상세 모델, 시편 합금·연마재 입도·RPM 수치는 자료에 없으면 추가하지 않는다.
- 교시 장치 전체 사진: 현재 자료에는 명확한 전체 teaching rig 사진이 없다. 실제 교시 카메라 프레임과 편집 가능한 좌표/장치 개념도로 설명한다.
- 저자·지도교수·제출 학기·심사 정보: 원본은 저자와 제출일이 placeholder이다. 성명·서명·승인 내용을 새로 만들지 않는다. 표지는 revised draft로 유지한다.
- 10/05 RA-L 제목 단서에 정확히 일치하는 파일은 지정 경로에서 찾지 못했다. 9/28 로컬 RA-L PDF는 논증 참고용으로만 읽었으며 9월 수치는 새 결과로 옮기지 않는다.
- 얼룩 중심 상대위치 학습과 방향 정렬·역변환은 구현되어 있으며 3장에 반영했다. E1/E2는 방향 정규화 OFF이므로 위치·방향 변화에 대한 정량 일반화 성과는 별도 실행의 실제 중심/각도·활성 옵션·task outcome을 연결해 추가한다. 곡면·새 결함·다중 학습 seed 검증도 현재 결과에 포함하지 않는다.
- blending/적응 속도 확장은 10/14 별도 개발 실행과 소스가 있다. E2 A/B/C 기본 비교에 합치지 않는다. residual RL의 검증된 학습/시험 성과는 확인되지 않았다.
