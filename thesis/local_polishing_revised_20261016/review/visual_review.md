# PDF 시각 검토 — E1/E2 결과 갱신본

최종 PDF는 99쪽이다. 변경·연결 페이지 60쪽(목차/목록/초록, 서론 RQ·범위, 6장부터 국문요약까지)을 렌더링해 5개 contact sheet에서 검토했다. 정확한 PDF 페이지 목록과 렌더 경로는 `render_index.json`에 기록한다. 바이트 단위로 동일한 2–5장은 기존 검토를 재사용했다.

- 목차·그림목차·표목차와 새 E1/C5–C6 번호, 쪽 번호, 초록의 결과 범위를 대조했다.
- 6장 pass_height_ref_v2와 E1 실제 수신 기록/E2 보관 주기의 구분을 확인했다.
- E1 주15회 그림의 C1–C5, 개별 점과 평균±표본SD, 공통 Q95 기준, C6가 분리된 표·패널의 캡션을 확인했다.
- E2 A4는 성공 완료시간 점이 아닌 중단 표식이며 A 완료시간 n=4와 전체시도 n=5가 구분돼 있다.
- 논의·결론·부록의 주장 범위, 구형 E1의 역사적 위치, 실제 사진·히트맵 캡션을 확인했다.
- E1 주 결과표(PDF 62쪽), C5/C6 표(65쪽), E2 완료/전체시도 시간표(67쪽), 국문요약(99쪽)을 별도로 확대 검토했다.
- 서론·논의·부록 끝에 소수 문장만 별도 페이지로 남던 부분은 직접 연결되는 문장의 중복을 줄여 정리했다.

잘린 표·수식 넘침·그림 겹침·한글 깨짐·누락 그림은 발견되지 않았다. 전체 빌드와 61개 산출물 검사가 통과했고, 미정의 참조/인용과 overfull box는 없다. 잔여 경고는 기존 KoTeX/microtype font patch 및 PDF page.1 destination 두 건이며 `unresolved_warnings.md`에 기록했다. figure/table 번호나 LaTeX label 중복 경고는 아니다.

렌더 이미지들은 로컬 검토 폴더에 보존한다. ZIP에는 원고·검사·렌더 인덱스 기록을 포함하고 대량의 검토용 이미지는 제외한다. 학교 제출/심사 승인이나 미확정 표지 메타데이터를 확정한 검토는 아니다.
